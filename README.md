# ⚡ Speed Type - Typing Speed Tester

A modern, responsive typing speed tester web application built with vanilla JavaScript, HTML, and Tailwind CSS.

## 🚀 Features

- **Real-time WPM Calculation** - See your words per minute as you type
- **Accuracy Tracking** - Monitor your typing accuracy percentage
- **Error Highlighting** - Visual feedback for correct/incorrect characters
- **Multiple Difficulty Levels** - Easy, Medium, and Hard text samples
- **60-Second Timer** - Standard typing test duration
- **Beautiful UI** - Modern gradient design with smooth animations
- **Responsive Design** - Works perfectly on desktop and mobile
- **Keyboard Shortcuts** - Quick controls for better UX
- **Results Modal** - Detailed stats when test completes

## 🛠️ Tech Stack

- **HTML5** - Semantic markup structure
- **CSS3** - Custom styles and animations
- **Tailwind CSS** - Utility-first CSS framework
- **Vanilla JavaScript** - Pure JavaScript with ES6+ features
- **Google Fonts** - Inter and JetBrains Mono fonts

## 🎮 How to Use

1. **Select Difficulty** - Choose between Easy, Medium, or Hard text samples
2. **Click Start Test** - Begin the 60-second typing challenge
3. **Start Typing** - Type the displayed text as accurately and quickly as possible
4. **View Results** - See your final WPM, accuracy, and error count

### Keyboard Shortcuts

- `Ctrl/Cmd + Enter` - Start the test
- `Escape` - Reset the test
- `Tab` - Navigate between elements

## 📊 Metrics Explained

- **WPM (Words Per Minute)** - Standard typing speed measurement
- **Accuracy** - Percentage of correctly typed characters
- **Errors** - Total number of incorrect characters
- **Time** - Countdown timer in seconds

## 🔧 Installation & Setup

1. Clone or download the project files
2. Open `index.html` in your web browser
3. Start typing!

No build process or dependencies required - it's a pure front-end application.
